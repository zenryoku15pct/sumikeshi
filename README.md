# スミケシ（sumikeshi）— 検証機能つきPDFマスキングツール

手書き書類を連続スキャンしたPDFの「毎ページ同じ位置」にある個人情報（氏名欄など）を、
マウスドラッグで矩形指定して**全ページ・複数PDFに一括マスキング**するデスクトップアプリです。
ネットワークは一切使いません（通信もせず、待ち受けの口も開きません）。

学校現場（生徒の答案・調査票をAIサービス等に渡す前の下ごしらえ）を想定して作りましたが、
アンケート・申込書など「同じ様式の紙が大量にある」場面なら同じように使えます。

**ほかの黒塗りツールと違う点は、塗ったあとに「本当に消えたか」を機械で全ページ検査できることです。**

このツールは「外部に出してよいか」を決めるものではありません。出してよいかどうかは
勤務校の規程と管理職の判断が先で、マスキングはそれが許された後の安全策です。

## 特長

- **復元不可能なマスキング**：黒い四角を上に重ねるだけの「見た目の黒塗り」ではなく、
  PDF内の画像データそのもの（ピクセル）を消去します。あとから剥がして中身を見ることはできません。
- **マスキングと同時に自動検査**：塗ったあと、書き出したPDFを読み直して本当に消えたかを
  機械で確かめ、消え残りがあれば画面に✕を出します。**画面の「✓ 枠内クリア」は
  「指定した枠の内側について消え残りが見つからなかった」という意味です。**
  枠の縁を横切って外へ続く字（枠より長く書かれた氏名）は⚠で知らせますが、枠から離れた
  別欄・対象外にしたページ・ファイル名は見ていません（用紙全体の安全保証ではありません）。目視では追えない枚数と、スキャナのMRC圧縮が作る
  隠れた画像レイヤーまで見ます（あとから単体で検査し直すこともできます＝`check_masked.py`）。
- **OCRテキスト層・メタデータも除去**：スキャナが埋め込んだOCRテキストも正規の墨消し処理で
  除去し、PDFのメタデータ（タイトル・作成者・XMP）も自動で消去します。
- **完全ローカル処理**：外部への送信は一切ありません。読み込んだPDFは表示のために読むだけで、
  原本ファイルは変更しません。通信もせず、待ち受けの口（ポート）も開きません。
- **複数PDF一括・ファイルごとの個別設定・プリセット保存**に対応。

## 入手方法

### A. 実行ファイル版（推奨・Pythonのインストール不要）

[Releases](../../releases) から自分のOSのZIPをダウンロードして展開するだけです。
（Windowsは**ZIPを右クリック→「すべて展開」**してから使ってください。ZIPを開いた
ウィンドウの中で直接ダブルクリックすると、必要なファイルがそろわず動きません）

| ファイル | 対象 | ダブルクリックするもの |
|-|-|-|
| `sumikeshi-windows.zip` | Windows | `sumikeshi.exe` |
| `sumikeshi-macos-apple-silicon.zip` | Mac（Appleシリコン：M1以降） | `スミケシ.app` |

（Intel Mac＝2020年頃までの機種は、下の**ソース版**を使ってください）

ダブルクリックすると**アプリの窓がそのまま開きます**。黒い画面（ターミナル）もブラウザも
出ません。終了は窓を閉じるだけです。
マスキング後の検査は、アプリの中の「**検査**」から行います（v1系にあった
`sumikeshi-check` は、アプリに取り込んだので無くなりました）。

同じフォルダの `お試し用PDF/ダミー調査票.pdf` は、練習用の架空の書類です（4ページ・
氏名欄はすべて架空の名前）。まずはこれで、矩形を1つ引けば全ページから消えることを
試してみてください。

**初回だけ、OSの警告が出ます**（開発元の署名を購入していないためで、異常ではありません。
中身はこのリポジトリのソースそのものです）：

- **Windows**：青い「WindowsによってPCが保護されました」→「**詳細情報**」→「**実行**」
- **macOS**：「開発元を検証できません」→ システム設定 → プライバシーとセキュリティ →
  下部の「**このまま開く**」（古いmacOSでは右クリック→「開く」でも可）

**ウイルス対策ソフトが `sumikeshi` を誤って削除する場合があります。**
署名のないPython製アプリに起きやすい誤検知で、ウイルスではありません
（中身はこのリポジトリのソースそのものです）。その場合は、お使いのウイルス対策ソフトの
例外設定（除外リスト）に展開先フォルダを追加するか、下の**ソース版**を使ってください。

### B. ソース版（Pythonがある人・中身を確かめたい人向け）

**macOS**

1. このリポジトリをダウンロードして展開（緑の「Code」→「Download ZIP」）
2. `セットアップ.command` をダブルクリック
   - Python 3 が無いと言われたら：ターミナルで `xcode-select --install` を実行してから再度
3. 以後は `スミケシ起動.command` のダブルクリックで起動

**Windows**

1. [python.org](https://www.python.org/downloads/) から Python 3 をインストール
   （**「Add python.exe to PATH」に必ずチェック**）
2. このリポジトリをダウンロードして展開し、`セットアップ.bat` をダブルクリック
3. 以後は `スミケシ起動.bat` のダブルクリックで起動

セットアップ時に、お試し用のダミーPDF（架空の氏名入り・`samples/ダミー調査票.pdf`）が生成されます。
実行ファイル版はGitHub Actions（`.github/workflows/build.yml`）がこのソースから自動ビルドしたものです。

## 使い方（5ステップ）

1. **PDFを読み込む** — 画面左にPDFをドラッグ＆ドロップ（複数可）
2. **マスク位置を指定** — 右のページ表示の上をドラッグして矩形を追加（複数可）。
   ページ送り（◀▶ または ←→キー）で他のページの位置ズレを確認。
   矩形はクリックで選択、ハンドルでサイズ変更、Deleteで削除。ファイルごとに記録されます。
   **枠は欄の印刷線より一回り大きく**（ふりがな・訂正書き・はみ出した字ごと囲む）。
3. **設定** — 塗りつぶし色（黒/白）、適用ページ範囲（空欄=全ページ）、奇数/偶数ページのみ
   （両面スキャン対応）。「この設定を全ファイルへコピー」で一括設定もできます。
4. **マスキング実行** — `output/` に `元ファイル名_masked.pdf` として保存されます
   （原本は無変更）。**`output/` の直下に置かれるのは「枠内クリアの最新版」だけ**です。
   要確認・消え残りの出力は `output/要確認/` に `_要確認` 付きの名前で分けて置かれ、
   同じ原本を塗り直すと古い出力は `trash/` へ退避されます。
5. **渡す直前にもう一度「検査」** — 実際に外へ渡すフォルダそのものを「検査」に掛けて
   ください。処理し忘れの原本が紛れていれば、検査項目[0]（処理済みの印）が捕まえます。
   実行直後の✓は「今回処理したファイル」の話です。渡すフォルダに後から足したファイルは
   見ていません。✕・要確認が1件でもあれば送らないでください。

## 全ページ自動検査（外部へ渡す前の関門）

マスキング後のPDFを機械で全ページ検査します。**外部（AIサービス等）へ渡す前に必ず通してください。**

- **アプリから**：画面左の「**検査**」→「マスク済みPDFを検査する…」→ フォルダを選んで実行。
  ファイルごと・ページごとの結果が一覧で出ます
- **コマンドから**（ソース版・大量処理や自動化向け）：

```
python3 check_masked.py output/
```

（Windows は `.venv\Scripts\python check_masked.py output\`）

どちらも `検査レポート/検査レポート_日時.md` にページごとの合否表が残ります
（`output/` の外に置くのは、レポートにはファイル名や元のメタデータが載るため、
人に渡すフォルダへ紛れ込ませないためです）。
コマンド版の終了コードは 合格=0 / 不合格・要確認あり=1。

### 検査する5項目

|項目|見るもの|落ちる例|
|-|-|-|
|[0] 処理痕跡|残存メタデータが無いか・**処理済みの印**があるか|そもそもツールを通っていないファイルが紛れている（印の無いPDFは要確認）|
|[1] 画像レイヤー|**全レイヤー**のマスク領域が均一か|黒い四角を重ねただけ／MRCの下層に氏名が残る|
|[1.5] 枠の縁|枠のすぐ外側に、縁を横切って続く字が無いか（要確認どまり）|氏名が欄より長く書かれていて、最後の1字が枠の外に残る|
|[2] テキスト層|マスク領域内の文字が0か|OCR文字が黒塗りの下に残っている|
|[2.5] 線画|マスク領域に掛かる線（ベクターの筆跡）が無いか|タブレット記入の署名が黒塗りの下に座標のまま残っている|
|[3] 注釈|注釈が0件か（PDFの生の一覧から数える）|注釈で黒塗りしている（剥がせる）／フォーム入力欄に氏名が残る|
|[4] レポート|上記をページごとに表で出力|—|

出力のPDFには「スミケシで処理済み」の小さな印（個人情報を含まないメタデータ1項目）が
入ります。検査は印の無いPDFを「未処理の疑い」として要確認に落とします
（v2.0.0より前の出力には印がありません）。

**[1]がこのツールの肝です。** スキャナのMRC圧縮は1ページを複数の画像レイヤーに分けて
持つため、見た目が真っ黒でも下の層に文字が残ることがあります。全レイヤーを個別に取り出して、
マスク領域のピクセルが均一かどうかで判定します。

### マスク領域の決め方（3段構え）

1. `--preset 名前` または `--rects "x0,y0,x1,y1"`（正規化座標）で明示指定 ← **最も確実**
2. 指定がなければ自動検出（黒の均一ブロックを探す）
3. どちらでも見つからなければ「マスク痕跡なし」として要確認に落とす（黙って合格にはしません）

**白で塗った場合、自動検出は使えません**（紙の余白と区別できないため）。
`--preset` か `--rects` で領域を渡してください。

### 検査そのものの動作確認

検査が漏れを本当に捕まえられるかを、わざと壊したサンプルで確かめられます。

```
python3 make_dummy_sample.py
python3 make_leak_samples.py
python3 check_masked.py samples/leak-check/ --no-report
```

`samples/leak-check/` に8本が作られます。自動検出のまま掛けると **01（正常）は
「要確認」**（自動検出は合格を出さない仕様）、02〜07 が不合格、08（枠の外にはみ出し）が
要確認になれば正常です。`--rects "0.5418,0.1080,0.9273,0.1825"` を付けて掛け直すと、
01だけが合格になり、08は要確認のままです（枠の内側は消えているが、字が枠より長い）。

## 検査の限界（必ず読んでください）

**「✓ 枠内クリア」＝指定したマスク枠の内側について消え残りが見つからなかった、という
意味です。** 用紙全体の保証ではありません。次は機械では守れないので、人が現物で判断
してください。

1. **枠からのはみ出し**：氏名が矩形からはみ出して書かれている・スキャンの置きずれ・
   コピーの変倍でレイアウトがずれている場合、枠の外に残った部分は消えません。
   枠の縁を横切って続く字は検査[1.5]が⚠で知らせますが（v2.0.0で追加。作者自身が
   お試し用PDFで「最後の1字が枠の外に残ったまま✓」を実機で見つけたのが理由です）、
   薄い字・細い画・枠から離れた位置の字は拾えず、字の途中で枠を切った場合も
   切った位置によっては拾えません（要確認に落とす網であって、合格の根拠ではありません）。
   → **対策は矩形を気持ち大きめに囲むこと**（これが本質的な防御です）。
   束の一部のページだけ枠の下が空白のときは「そのページだけ枠がずれていませんか」と
   警告が出ますが、ずれた先に別の印字があると機械には見えません。
2. **押さえ忘れた別欄**：保護者署名・緊急連絡先・自由記述の中に書かれた名前など、
   指定していない欄は検査対象外です。**押さえるべき欄がすべて入っているかは、
   用紙の現物を見て人が決めてください。**
3. **マスクは匿名化ではありません**：氏名欄を消しても、筆跡・記述の内容・学級名などから、
   本人や周囲の人には誰の書類か分かります。文集・実例集などへの公開・掲載は、
   消えたかどうかとは別に、本人の同意と利用目的で判断してください。
4. **ファイル名は検査対象外です**：氏名入りのスキャン名は出力にも引き継がれ、
   検査レポートにもそのまま載ります。
5. **ページ範囲・奇数偶数で外したページは検査もされません**：対象外のページの枠の
   場所に中身が残っていれば⚠で知らせますが、✓の対象は処理したページだけです。

なお、次の危ない紙は**塗らずに止まります**（v2.0.0で追加した門番）：
束の中に向き・大きさの違うページが混じっている／切り取り（トリミング）がある／
読み込んだあとに原本が差し替わった。止まったときは、表示された理由に従って
PDFを整えてから読み込み直してください。

## この道具が向かない仕事

- **ページごとに塗る場所・塗る範囲の判断が変わる文書**——会議録、指導記録、
  開示請求への対応（不開示部分の墨塗り）、自由記述の中に散らばる実名。この道具は
  「毎ページ同じ位置」を一括で塗るための物で、**「どこを塗るべきか」の判断は一切
  保証しません**。検査が見るのは「塗ると決めた場所が消えたか」だけです。
- 開示請求への対応は、開示担当・設置者との協議が先です。この道具の✓を判断の
  代わりにしないでください。

## 用紙・テストを設計するときの前提条件（作る側への注意）

このツールで氏名欄を消す予定の用紙を新しく設計するときは：

- **黒い帯・黒背景の見出しを入れない。** マスクの自動検出が黒の均一ブロックを探すため、
  タイトルの黒帯があると「マスク済み」と誤認し、塗り忘れページを見逃す方向に働きます
- 氏名欄は罫線の枠だけにし、周囲に余白をとる（矩形を大きめに囲めるように）

## コツ・注意

- スキャンは1〜2mmずれることがあるため、**矩形は気持ち大きめ**に囲んでください
- マスク前の元スキャンは所定の隔離フォルダに移し、不要になったら削除してください
  （`_masked` という名前でも、処理し忘れたファイルが紛れることがあります。
  だからこそ検査を必ず通してください——検査項目[0]がそれを捕まえます）
- ファイル名に個人名が入っている場合、出力ファイル名にも引き継がれます。
  外部に渡す前にファイル名を変更してください
- **プリセットは座標しか覚えていません。** 用紙の様式を変えた・別のスキャナに変えた・
  年度が替わったときは、呼び出して済ませず作り直してください。枠を引いたときの紙の形は
  プリセットにも記録され、形の違う紙に当てると実行時に止まりますが、同じ形のまま
  欄の位置だけ変わった様式は機械には見えません
- 白で塗ると、塗った場所も塗り残しも目では確認できません。**白を使うときこそ矩形を
  大きめに**（白なら大きくしても見た目は変わりません）。受け取る側には空白にしか
  見えないため、送り状に「氏名欄は意図的にマスキング済み」と一言添えてください
- **締切当日の朝を初回にしないでください。** 初回はOSの警告・ウイルス対策ソフトの
  誤検知で数分〜数日かかることがあります。前日までに、同梱の「お試し用PDF」で
  1回通しておいてください
- **動かなかった日に、PDF閲覧ソフトの注釈やWordの図形で黒い四角を重ねて代用しないで
  ください。** 重ねた四角は受け取った側が1クリックで剥がせます。**オンラインの
  黒塗りサイトも使わないでください**（氏名入りの原本をそのまま外部サーバーへ送ることに
  なります）。間に合わないときは、提出期限の相談のほうが安全です

## クラウド同期・共有フォルダの中で使う場合（OneDrive・Google ドライブ・校内サーバー）

- **共有フォルダの中に「隔離」はありません。** 共有の中にある限り、原本は閲覧権限の
  ある全員に見え続けています。マスク前の原本は、共有フォルダの外（自分のPCの専用
  フォルダ）へ移してください。
- **「空き容量を増やす」は削除ではありません。** このPCから見えなくなるだけで、
  クラウド側と共有相手からはそのまま見えています。本当に消すときは、ブラウザで
  クラウド側を開いて削除し、ごみ箱からも削除するところまでが1セットです。
- **渡すときは、フォルダのリンク共有ではなく、`output/` の中身だけを新しい場所へ
  コピーして渡してください。** 上の階層ごとリンクを送ると、原本や検査レポートまで
  一緒に開きます。`output/` への共有リンクの張りっぱなしもやめてください。
- **校内サーバーに置いた1つのアプリを、全員で直接実行しないでください。**
  `output/` が共有上にでき、マスク済みPDFが権限のある全員から見える場所に溜まります。
  使う人ごとに自分のPCへコピーしてから使ってください。

## 人に薦めるとき・校内で配るとき

- **自分が使っているフォルダをコピーして渡さないでください。** `output/`（マスク済み
  PDF）、検査レポート（ファイル名の一覧）、自分で入れた元スキャンが同居しています。
  渡すのは Releases のZIP、またはこのページのリンク（URL）です。
- 手順書を自作するなら、**次の2行だけは削らないでください**——
  「✓は塗った枠の中だけの合格印。枠の外と、自由記述の中に書かれた名前は守れない」
  「様式が変わったら枠を引き直す。新様式の初回は、出来上がりを現物で1枚確認する」。
- 旧版（起動すると黒い画面とブラウザが開く版）を校内で見つけたら、差し替えてください。
  以後の修正が届きません。

## やめるとき・PCを手放すとき

マスキングが済んでいても、PCの中には生徒のデータが残っています。返却・廃棄・担当交代の
前に、次の4か所を点検してください（1分で終わります）。

1. 原本の隔離フォルダ（自分で決めた場所）
2. `output/`（`要確認/` を含む）
3. `検査レポート/`
4. `presets/`・`trash/`

| `gui.py` | 画面（PySide6）。アプリの入口 |
| `masking.py` | マスキングの中核（画面から独立。PyMuPDFのリダクション） |
| `check_masked.py` | マスク後の全ページ自動検査（コマンドとしても単体で動く） |
| `make_dummy_sample.py` | お試し用ダミーPDF（架空の氏名入り）の生成 |
| `make_leak_samples.py` | 検査の動作確認用に「わざと漏らしたPDF」7本を生成 |
| `make_icon.py` | アプリのアイコンの生成元 |
| `tests/` | 中核が旧版と同じ結果を出すか・画面の動き・漏れを見逃さないかの自動テスト |
| `assets/` | アイコンなど |
| `output/` | マスキング済みPDFの出力先（直下は枠内クリアの最新版だけ） |
| `output/要確認/` | 要確認・消え残りの出力（`_要確認` 付きの名前） |
| `検査レポート/` | 検査レポート（ファイル名・元メタデータが載るため出力とは分ける） |
| `presets/` | 保存した矩形設定（JSON） |

出力先（`output/` `presets/`）は、Windowsではexeと同じフォルダ、macOSでは
`スミケシ.app` と同じ階層にできます。アプリを書き込めない場所（`/アプリケーション` など）
へ置いた場合は、`書類/スミケシ/` の下にできます。画面の「出力フォルダを開く」で確認できます。
